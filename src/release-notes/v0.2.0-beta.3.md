## 新功能

- 更新到新版後，app 會自動顯示**更新內容**視窗，列出還沒看過的 release notes。
- 設定中心的**更新**頁新增「查看更新內容」，可以隨時重新打開目前版本的說明。
- Release notes 會從 app 內建的 Markdown 載入，支援新功能、改善、修正與需要注意等分類。

## 改善

- 已讀版本會保存在本機，下次開啟同一版本時不會重複打擾。
- 更新內容支援 `code`、**粗體**與==重點標示==，讓重要資訊更容易掃讀。
- 在非桌面預覽環境中會使用最新內建 release note 版本，方便開發與檢查內容。

## 需要注意

- 若某個版本沒有內建對應的 release note，手動查看本版更新內容時不會開啟視窗。
